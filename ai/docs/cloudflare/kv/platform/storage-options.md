# Storage Options

Cloudflare offers several storage products, each optimized for different use cases.

- **Workers KV**: Best for high-read, low-latency key-value data.
- **D1**: Best for relational data and SQL queries.
- **R2**: Best for large, unstructured objects (images, videos, backups).
- **Durable Objects**: Best for stateful coordination and strong consistency.
