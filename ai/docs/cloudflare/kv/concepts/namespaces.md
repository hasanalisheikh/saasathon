# KV namespaces

A KV namespace is a container for your key-value pairs.

## Keys and Values

- **Keys**: Up to 512 characters.
- **Values**: Up to 25 MB.
- **Metadata**: Up to 1024 bytes per key.

## Account Scoping

KV namespaces are scoped to your Cloudflare account. You can create multiple namespaces for different purposes.
