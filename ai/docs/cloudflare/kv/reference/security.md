# Data security

Cloudflare takes the security of your data seriously.

## Encryption

- **Encryption at Rest**: Data in Workers KV is encrypted at rest using industry-standard encryption.
- **Encryption in Transit**: All communication with Workers KV is encrypted via TLS.

## Compliance

Cloudflare maintains various compliance certifications including SOC 2, ISO 27001, and more.
