# Metrics and analytics

Workers KV provides metrics and analytics to help you monitor your application's performance and usage.

## Available Metrics

- **Read Operations**: Total number of successful read requests.
- **Write Operations**: Total number of successful write requests.
- **Delete Operations**: Total number of successful delete requests.
- **List Operations**: Total number of successful list requests.
- **Storage**: Total amount of data stored in your KV namespaces.

## Accessing Metrics

- **Dashboard**: View charts and tables in the Cloudflare dashboard under **Workers & Pages** > **KV**.
- **GraphQL Analytics API**: Query detailed metrics programmatically.
