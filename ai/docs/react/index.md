# React

React is the library for web and native user interfaces. Build user interfaces out of individual pieces called components written in JavaScript.

React is designed from the ground up for gradual adoption, and you can use as little or as much React as you need. Whether you want to get a taste of React, add some interactivity to a simple HTML page, or start a complex React-powered app, the links in this documentation will help you get started.
